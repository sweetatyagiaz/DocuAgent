# Sample Documents

Drop PDF/TXT/DOCX files here for the RAG pipeline to ingest in Phase 2.

Good demo content ideas:
- A company handbook / policy doc (refund policy, HR policy, etc.)
- A product spec or FAQ
- A research paper (to show technical Q&A grounding)

These will be chunked, embedded, and stored in ChromaDB so the agent's
RAG tool can retrieve relevant passages to answer questions.
